List itself is licensed under AGPL-3.0 (see LICENSE). It bundles and uses the following open-source components.

  docx-preview ........ Apache-2.0
  mammoth ............. BSD-2-Clause
  SheetJS (xlsx 0.18.5) Apache-2.0
  pptx-preview ........ MIT   (patched by tools/patch_pptx_preview.py, see below)
  JSZip ............... MIT
  marked .............. MIT

Android libraries
  Jetpack Compose, Activity, Media3 (ExoPlayer), Coil, androidx.webkit ... Apache-2.0

Converter for legacy formats (doc, ppt, odt, odp, rtf)
  x2t from ONLYOFFICE Document Server ... AGPL-3.0
  WebAssembly build by CryptPad: https://github.com/cryptpad/onlyoffice-x2t-wasm
  Source code: https://github.com/ONLYOFFICE/core
  If you distribute the app to other people, the AGPL requires you to give them the source code of the
  whole app.

Slide-rendering fixes (app/src/main/assets/pptx)
  fix.js and tools/*.py are part of List (AGPL-3.0).
  pptx/shapes.js is generated by tools/gen_pptx_shapes.py from the table of OOXML preset shapes that ships
  with LibreOffice (share/filter/oox-drawingml-cs-presets, MPL-2.0). The geometry itself is defined in
  ECMA-376 (ISO/IEC 29500, presetShapeDefinitions.xml). The generated file is derived from that table and
  stays under MPL-2.0 (LICENSES/MPL-2.0.txt). Its source form is the table, which is part of the LibreOffice
  source code: https://github.com/LibreOffice/core
  The patch tools/patch_pptx_preview.py adds hook calls to pptx-preview; pptx-preview keeps its own MIT license.
